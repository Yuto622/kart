# AURORA KART — Zenith Edition

ブラウザだけで動く 3D カートレース。ビルド不要・依存ゼロ（three.js を同梱するだけ）の
静的サイトで、`dist/` をそのまま配信すれば遊べます。

```
dist/
├── index.html      画面構造（メニュー / HUD / モーダル）
├── style.css       レイアウトとUI
├── game.js         ゲーム本体（描画・物理・AI・音・ポストエフェクト）
└── three.module.js three.js r170（同梱）
```

ローカルで動かす場合は、任意の静的サーバーで `dist/` を配信してください。

```sh
npx http-server dist -p 8080
# → http://127.0.0.1:8080
```

ES Modules を使うため、`file://` で直接開くのではなくサーバー経由で開く必要があります。

## 遊び方

| 操作 | キー |
| --- | --- |
| 加速 / ブレーキ / ハンドル | `↑ ↓ ← →` または `W A S D` |
| ドリフト | `Shift`（押しながら曲がる → 離すと加速） |
| アイテム | `Space` |
| 空中トリック | `E` |
| 視点切替（チェイス / ワイド / ロー / コックピット） | `C` |
| 後方確認 | `R` |
| フォトモード | `F` |
| 一時停止 | `Esc` または `P` |

スマートフォンは画面上のボタン、標準配列のゲームパッドにも対応しています。

### 走りを速くする4つの要素

- **パーフェクトスタート** — カウントダウンの「GO!」に合わせて加速すると大ブースト。
- **ドリフト** — 青 → オレンジ → 紫の3段階。段階が上がるほど離したときの加速が伸びます。
- **スリップストリーム** — 前のカートの真後ろに入り続けるとゲージが溜まって加速。
- **コイン** — 10枚まで最高速が上がり、コインマグネットでまとめて回収できます。

### モード

- **シングルレース** — 8台で競う本気の1レース。
- **グランプリ** — 4コース連戦。ゴール順位に応じて 15・12・10・8・6・4・2・1 点、合計で王者を決定。
- **タイムアタック** — 自己ベストがゴーストとして出走。区間差がリアルタイムで表示されます。

周回数（3 / 5 / 7）、ミラー（左右反転コース）、難易度（4段階）はメニューから変更でき、
自己ベストは設定ごとに別々に保存されます。

## 収録コンテンツ

**4コース**

| # | コース | 特徴 |
| --- | --- | --- |
| 01 | コーラル・コースト | 海沿いの高速レイアウト。灯台と港町。 |
| 02 | サンセット・メサ | 高低差のある峡谷。石橋と熱気球。 |
| 03 | スターライト・パス | 星空とオーロラ、ネオンのアーケードトンネル。 |
| 04 | エンバー・フォージ | 溶岩の海に架かる製鉄所。最速・最難関。 |

**4マシン** — SPRINT（バランス）/ COMET（最高速）/ MISTRAL（ドリフト）/ TITAN（重量）。
重量はライバルとの接触の押し合いにも影響します。

**7アイテム** — ⚡ターボ / ⚡トリプルターボ / ◉ホーミングオーブ / ▲スリップトラップ /
◇シールド / ϟサンダーパルス / ❍コインマグネット。順位が後ろほど強いものが出ます。

**7人のライバル** — NOVA・MILO・LUNA・RIO・PIP・SKYE・BEAU。
それぞれ「速さ」「コーナーの突っ込み」「ライン取りの丁寧さ」「仕掛けの積極性」「ミスの多さ」が
異なり、走り方が変わります。

## 技術メモ

- **描画** — three.js r170。コース・地形・装飾はスプラインから毎回生成し、静的メッシュは
  マテリアル単位でマージして描画コールを削減しています。
- **ポストエフェクト** — 自前の軽量コンポーザ（`buildPost` / `present`）。シーンを
  HalfFloat のレンダーターゲットに描き、輝度抽出 → 2スケールのガウスぼかし →
  合成パスでブルーム・コース別カラーグレード・色収差・放射状スピードブラー・
  陽炎・ビネット・グレインをまとめて適用します。「シネマ効果」オフや軽量画質では
  丸ごとスキップして直接描画に戻ります。
- **サウンド** — WebAudio で合成。ディチューンしたノコギリ波＋矩形波のエンジン音を
  速度とドリフトで駆動し、ノイズ源からタイヤ・風・歓声を作り、コース別の
  ステップシーケンサーで BGM を鳴らします（速度が上がるほどレイヤーが増えます）。
- **物理 / AI** — レースは 60Hz 固定ステップ。ライバルはコースの曲率から
  「イン側に着けるライン」を計算して走ります。
- **保存データ** — `localStorage` に自己ベスト・ゴースト・設定・通算成績を保存します
  （キーは `aurora-v3-*` / `aurora-preferences` / `aurora-profile`）。
- **アクセシビリティ** — `prefers-reduced-motion` を尊重し、画面の揺れ・スピードライン・
  紙吹雪を抑制します。WebGL が使えない場合は案内モーダルを表示します。
