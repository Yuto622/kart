# AURORA KART / U-Speak Racers

ブラウザだけで動く 3D カートレース。**走りながら英単語を解く**学習モードと、
**友だちと同時に走るオンライン対戦**を備えています。ビルド不要・依存パッケージ 0。

```
dist/                     静的サイト（これだけでオフライン版は動く）
├── index.html            画面構造（メニュー / HUD / 待機室 / モーダル）
├── style.css             レイアウトとUI
├── game.js               ゲーム本体（描画・物理・AI・音・クイズ・通信）
├── vocab.js              英検 5/4/3級の語彙 326語
├── net.js                WebSocket クライアント
└── three.module.js       three.js r170（同梱）
server/
└── server.mjs            静的配信 ＋ ルームサーバー（Node標準ライブラリのみ）
```

## 起動

**オンライン対戦まで含めて遊ぶ（推奨）**

```sh
node server/server.mjs --port 8080
# → http://localhost:8080
# → 同じWi-Fiの友だちは http://<あなたのIP>:8080  （起動時に表示されます）
```

これ1つで静的配信とルームサーバーの両方が動きます。依存パッケージのインストールは不要です。

**ひとりで遊ぶだけなら**静的サーバーでも動きます（オンラインのタブだけ使えません）。

```sh
npx http-server dist -p 8080
```

ES Modules を使うため、`file://` で直接開くのではなくサーバー経由で開いてください。

別のホストにサーバーを置く場合は `?server=wss://example.com` を URL に付けるか、
`localStorage.setItem('aurora-server','wss://example.com')` で接続先を上書きできます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 加速 / ブレーキ / ハンドル | `↑ ↓ ← →` または `W A S D` |
| ドリフト | `Shift`（押しながら曲がる → 離すと加速） |
| アイテム | `Space` |
| 空中トリック | `E` |
| 視点切替（チェイス / ワイド / ロー / コックピット） | `C` |
| 後方確認 | `R` |
| フォトモード | `F` |
| 一時停止 | `Esc` または `P` |

アイテムキーは**長押しでこうら・バナナを後ろに構えて防御**、はなすと発射。`↓` と同時に使うと
後方へ撃てます。スマートフォンは画面上のボタン、標準配列のゲームパッドにも対応しています。

レース開始前にはコースのフライバイが入ります（`Space` / タップでスキップ）。そのあと
スタートランプが3つ点灯 → 全部緑でスタートです。

### 走りを速くする要素

- **パーフェクトスタート** — スタートランプが全部緑になる瞬間に加速すると大ブースト。
- **ドリフト** — 青 → オレンジ → 紫の3段階。段階が上がるほど離したときの加速が伸びます。
- **スリップストリーム** — 前のカートの真後ろに入り続けるとゲージが溜まって加速。
- **コイン** — 10枚まで最高速が上がります。
- **グライダー** — 大ジャンプ台で翼が開きます。光のリングをくぐると滞空が伸びます。
- **反重力ゾーン** — タイヤが横を向く区間。ここでは相手とぶつかると**両者スピンブースト**。
- **ダートのショルダー** — 道の外は減速。ガードレールのない区間で落ちると引き上げられ、
  タイムをロスします。

| ⚡ | ダッシュキノコ | ブースト |
| ⚡ | トリプルキノコ | ブースト3回ぶん |

### モード

- **レース** — 8台で競う本気の1レース。
- **グランプリ** — 4コース連戦。ゴール順位に応じて 15・12・10・8・6・4・2・1 点、合計で王者を決定。
- **タイム** — 自己ベストがゴーストとして出走。区間差がリアルタイムで表示されます。
- **U-SPEAK** — 走りながら英単語。下の「U-Speak Racers」を参照。
- **オンライン** — 合言葉で部屋をつくって、友だちと同時に走る。

## U-Speak Racers（英単語 × レース）

**設計思想**：問題を解くことが攻略手段そのもの。正解＝加速、不正解＝減速。
「勉強させられている」のではなく「速く走りたいから単語を覚える」状態をつくります。

**コアループ**

```
走る → チェックポイント通過 → 出題（8秒）
  → 正解：ブースト（最高速 +30% を3秒）＋ 連続正解カウント
  → 不正解／時間切れ：スピン（1秒停止）
  → また走る
```

- 出題数は周回数で決まります（**1周=5問 / 2周=8問 / 3周=9問**）。
- 形式は **絵文字＋日本語 → 英単語の3択**。誤答の選択肢は**同じ級から**選ばれるので難易度がそろいます。
- 級は **英検 5級 / 4級 / 3級**（収録 326語）。メニューまたは待機室で選べます。
- 回答は `1` `2` `3` キー、またはタップ／クリック。**走りながら**答えます。
- リザルトに正答数・最大連続正解と、**まちがえた単語の一覧**が出ます。
- 通算の正解数はブラウザのプロフィール（WORDS）と、サーバーの記録の両方に貯まります。

## オンライン対戦

- 「オンライン」タブ →「部屋をつくる」で **4文字の合言葉**が出ます。友だちはそれを入れて参加。
- **最大8人**。空いた席は **CPU が自動で埋めます**（CPU はホストが動かし、全員の画面で同じ動きになります）。
- 待機室は**最大60秒**。ホストの「このメンバーでいく」でいつでも即発進。
- ホストがコース／周回（1〜3周）／英検の級／クイズの有無を決め、全員に同期されます。
- 全員が**同じ問題**を同じ順で解きます（部屋ごとのシードから生成）。
- 順位・タイム・正答数はサーバーに保存され、`GET /records` で確認できます
  （`server/data/records.json`）。

周回数（3 / 5 / 7）、ミラー（左右反転コース）、難易度（4段階）はメニューから変更でき、
自己ベストは設定ごとに別々に保存されます。

異なり、走り方が変わります。

## 技術メモ

- **描画** — three.js r170。コース・地形・装飾はスプラインから毎回生成し、静的メッシュは
  マテリアル単位でマージして描画コールを削減しています。
- **ポストエフェクト** — 自前の軽量コンポーザ（`buildPost` / `present`）。シーンを
  HalfFloat のレンダーターゲットに描き、輝度抽出 → 2スケールのガウスぼかし →
  合成パスでブルーム・コース別カラーグレード・色収差・放射状スピードブラー・
  陽炎・ビネット・グレインをまとめて適用します。「シネマ効果」オフや軽量画質では
  丸ごとスキップして直接描画に戻ります。
- **サウンド** — WebAudio で合成。ディチューンしたノコギリ波＋矩形波のエンジン音を
  速度とドリフトで駆動し、ノイズ源からタイヤ・風・歓声を作り、コース別の
  ステップシーケンサーで BGM を鳴らします（速度が上がるほどレイヤーが増え、ファイナルラップ
  ではテンポとキーが上がり、スター中はきらめくトップラインが乗ります）。
- **物理 / AI** — レースは 60Hz 固定ステップ。ライバルはコースの曲率から
  「イン側に着けるライン」を計算して走り、ジャンプ台では一緒に飛んでグライダーを開き、
  自分の順位に応じたアイテムを持って前の走者に使ってきます。
- **コース区間** — 各コースは「ガードレールのない区間（落下あり）」と「反重力区間」を
  持ち、区間データからガードレール・警告ポスト・発光パネルを自動生成します。
- **通信** — サーバーは中継のみ。各自が自分のカートを計算して 15Hz で位置を送り、
  受信側は 130ms の補間バッファで滑らかに描きます。時刻は ping/pong のオフセットで
  合わせ、スタート時刻とクイズのシードを全員で共有します。CPU はホストが計算して
  配信するので、全員の画面で同じ挙動になります。WebSocket は RFC 6455 の
  ハンドシェイクとフレーミングを `server/server.mjs` に直接実装しています（依存ゼロ）。
- **保存データ** — `localStorage` に自己ベスト・ゴースト・設定・通算成績を保存します
  （キーは `aurora-v3-*` / `aurora-preferences` / `aurora-profile` / `aurora-name`）。
  オンラインの戦績はサーバー側の `server/data/records.json` に貯まります。
- **アクセシビリティ** — `prefers-reduced-motion` を尊重し、画面の揺れ・スピードライン・
  紙吹雪を抑制します。WebGL が使えない場合は案内モーダルを表示します。
